自我介绍与简历经历

面试官想考什么

  • 你是谁，专业和岗位是否匹配。
  • 你是否真的围绕 Web 安全和安全服务学习。
  • 你的比赛、项目、博客能不能支撑岗位。
  • 你是否能稳定到岗并长期实习。

你上次的问题

你只说了学校、专业、网络安全协会和 Web 方向，太像普通学生介绍，没有把安全服务岗位最关心的内容讲出来：

  • Web 漏洞分析。
  • 服务加固。
  • 流量分析。
  • WebShell 排查。
  • 日志分析项目。
  • 到岗时间和实习稳定性。
